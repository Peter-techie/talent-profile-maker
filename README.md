# Talent Profile Maker

A beginner JavaScript project that takes messy text, cleans it, and builds a talent profile sentence. It is the first small step toward my skills-to-income and talent showcase app idea.

## What it does

- Cleans messy input with `trim()` and `toLowerCase()`
- Capitalises names and cities with `toUpperCase()` and `slice()`
- Fixes a skill with `replace()`
- Builds a sentence with template strings
- Checks a fake search with `includes()`
- Makes a short preview with `slice()`

## Example output

```
My name is Emmanuel, I am an AI Engineer from Uyo.
Does the search engineer match the profile sentence? true
My name is Emmanuel, I am...
Emmanuel is an engineer from Uyo.
```

## How to run it

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Press **F12** and open the **Console** tab.
